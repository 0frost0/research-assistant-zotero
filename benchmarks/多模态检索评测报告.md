## 人工相关性

真实人工评分 0 条、标准答案确认 0 条。原始 Top-10 正例共 180 个待评位置；显示排名返回 125 个待评位置（文字 43、图片 39、混合 43）。覆盖率为 0%，平均等级与已评相关率均为“未统计”，不是 0 分。界面可提交 0~3 分和审阅备注，已评相关率以等级至少 2 为相关，未评结果不放进分母。

确认标准答案和评判检索结果是独立操作；人类可以认为一个未列入草案 ID 的结果同样有用，这时应在新的数据集版本中补全等价证据，而不是直接把草案当作穷尽真值。

## 发现

1. 同源上限造成显著显示损失。例如 T04 原始目标排第 4、T05/T06 排第 8；I01/I05 排第 6、I04 排第 5，分数全部超过 0.35，但前面同文献的其他结果占用 3 个名额。原始整体 R@10 83.3% 降为显示 47.2%。保留当前基线，后续应消融同源限制。
2. M01、M03 的指定证据没有出现在原始前 10；M05、M06 只找到部分证据。混合 MRR 0.667 不代表完整回答，混合 Recall@10 仅 50%。
3. 两个无答案对照都返回阈值以上内容，检索层没有正确拒绝。实验未生成回答，不能据此断言最终回答一定错误。
4. 原始页码召回 100% 而证据召回不足，说明标题、相邻段落、参考内容等同页命中不足以支撑结论。
5. 4 个自匹配检查全部在原始前 10 取得期望组，证明图片和图文输入协议工作；这些输入直接来自被索引图片，不能据此宣称独立图片查询达到 100%。

## 结论与下一步

统一模型具有文字与图像检索能力，但当前系统尚不能确认满足科研文本检索要求。首要问题是同源展示截断、混合证据完整性与无答案阈值，而不是向量维度或两模型空间错配。

下一步先人工审阅并冻结 gold，再用新论文和独立提问建立留出集。按文献或任务分组划分，避免同一张图的近义问法同时出现在调参集和测试集。扩充独立图片输入，而非复用已索引图；文字长段、跨页表格、图文联合及不可回答问题均应覆盖。验收阈值需要按真实科研任务约定，不能从 6 题/组推导普适达标线。

表格存储的 113 张可解析/12 张缺失结构是解析覆盖率，不是单元格准确率。应另标注表头、坐标、原值、单位与期望 SQL 结果，评测数字正确性后再让 Agent 自动推导数值。

## 自动回归与上下文策略

新运行：`46dc22d3-2ccf-4a4c-a0d3-930d08716045`，UTC 2026-09-06 15:43:06；原始导出 `retrieval_run_46dc22d3-2ccf-4a4c-a0d3-930d08716045.json`。24 题全部完成，检索计时 5.05 秒，不含初始化。整库、gold、模型及 collection 与旧运行一致，仍为 4169 点；未调用 DeepSeek、重新编码或修改原文献。

### 方法

生产路径与评测共用 `select_evidence()`：取消同源 cap3，排除明确的页眉/页脚/页码及图表纯转写文字点，按出处补回同一原始块的至多 1800 字符上下文，合并相同上下文。图片继续返回，未核验转写仅折叠保留，回答正文置空；表格提示数值/单位未核验。只改默认统一多模态后处理，其他基线未改动。

同一次编码/搜索最多取得 200 候选。旧 cap3 与新策略均在同批候选上取显示前 10，因此不把独立运行差异当作策略增益。多个后处理同时改变，本轮是组合策略对照，不是逐因素消融；改进发生在已用于诊断的开发集上，不是盲测。

显示 ID Recall/MRR 按代表点 ID 保持旧定义；新增 ContextRecall 计入该位置实际交付且对应本轮已检索、过阈值片段的等价 ID。只有交付上下文完全相同才合并，不能把同页任何内容都算命中。ContextRecall 不表示模型正确理解图片或生成正确答案。

### 回归与验收边界

`scripts/check_retrieval.ps1` 一次运行全部离线测试和固定评测，不在每次提问时执行，不触发新的 AI 评分。若任一开发正例当前 ContextRecall@10 低于同批候选旧 cap3 的 ID Recall@10，则保存新运行并退出 2。当前无此类退步，退出 0；原始 ID 退步另行展示。门槛只对照旧基线，不保证相对所有后续版本单调改善，也不检查回答正确率或无答案拒答。

63 项离线回归通过，桌面/手机实际检索及新旧运行切换检查通过；移除旧正文限高后，手机正文与图片没有溢出，浏览器错误/警告为 0。旧运行的 326 条 AI 初审及快照绑定重新校验通过；新运行 AI 审阅为空，真实人工评分与确认仍为 0。旧评分不能直接套用到扩展后的上下文。新结果可以用于开发回归，但不能宣布统一模型已满足科研检索要求。
