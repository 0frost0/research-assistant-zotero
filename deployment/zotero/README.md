# Research Assistant Bridge for Zotero

一个面向 Zotero 9 的轻量科研助手桥接插件。它将用户明确选择的 Zotero 分类同步到科研助手后端，并保留 PDF、批注和笔记之间的来源关系。

## 当前版本

- 插件版本：`0.2.0`
- 支持 Zotero：`9.x`
- 插件 ID：`research-assistant@local`
- 状态：Zotero 内部工作台测试版本

## 功能

- 按 Zotero 分类创建独立知识库。
- 在 Zotero 内部窗口完成检索、资料查看和专题笔记编辑，不再打开外部浏览器。
- 可配置并自动启动本机 Python 科研引擎。
- 可选择是否包含当前分类的子分类。
- 同步分类中的 PDF、PDF 批注和 Zotero 笔记。
- 相同 PDF 按内容哈希去重，可同时属于多个知识库。
- 在多个知识库中联合检索，并区分原文、批注和笔记来源。
- 从 Zotero 阅读器选区打开科研知识库检索。
- 将已确认的专题笔记新增回 Zotero。
- 相同笔记修订不会重复写回，不覆盖已有 Zotero 笔记。

## 安装

1. 在仓库的 **Releases** 页面下载最新的 `.xpi` 文件。
2. 打开 Zotero。
3. 进入 **工具 → 插件**。
4. 点击插件管理页面右上角的齿轮按钮。
5. 选择 **Install Add-on From File / 从文件安装插件**。
6. 选择下载的 `research-assistant-0.2.0.xpi`。
7. 按 Zotero 提示完成安装；如有提示，请重启 Zotero。

## 配置后端

插件不是独立的检索服务器，需要连接 Research Assistant 后端。

1. 启动科研助手 Web 服务。
2. 在 Zotero 中进入 **工具 → 科研知识库 → 配置后端连接**。
3. 输入后端地址，例如：

   ```text
   http://127.0.0.1:8765
   ```

4. 输入后端生成的连接令牌。
5. 插件会调用状态接口验证连接，成功后保存当前配置。

连接地址只允许：

- 本机 `http://127.0.0.1`、`http://localhost` 或 `http://[::1]`。
- 使用 HTTPS 的远程服务器。

地址中不能包含用户名、密码、查询参数或 URL fragment。

## 同步分类

1. 在 Zotero 左侧选择一个具体分类。
2. 进入 **工具 → 科研知识库 → 同步当前分类**。
3. 选择是否包含子分类。
4. 阅读并确认数据发送提示。
5. 等待同步完成。

插件只会同步本次选定分类中的受支持内容。同步期间如果分类内容发生变化，本次提交会终止，避免以不一致快照替换知识库成员。

## 打开知识库

完成同步后，进入：

```text
工具 → 科研知识库 → 打开知识库
```

插件会直接打开 Zotero 内部的科研助手工作台，并定位到最近同步的知识库，不会跳转到外部浏览器。

在 Zotero PDF 阅读器中选中文字时，也可以使用 **在科研知识库中检索**。

## 将笔记写回 Zotero

1. 在科研助手中创建并确认专题笔记。
2. 回到 Zotero。
3. 进入 **工具 → 科研知识库 → 将知识库笔记新增到 Zotero**。
4. 确认写回数量和目标分类。

写回操作遵循以下规则：

- 只写回已确认且未归档的笔记。
- 只新增笔记，不覆盖现有笔记。
- 使用笔记 ID 和修订号标记，同一修订不会重复写回。

## 隐私与安全

- 插件不会自动上传整个 Zotero 资料库。
- 只有用户选择分类并确认后，相关 PDF、批注和笔记才会发送到配置的后端。
- 插件不会读取其他插件保存的翻译密钥。
- 插件不会自动调用全文翻译或生成模型。
- 单个 PDF 最大上传大小为 25 MB。
- 未下载到本机的附件不会被静默跳过；本次同步会明确失败。
- 连接令牌不会放在知识库页面的普通 URL 查询参数中。

在使用远程服务器前，请确认服务器由你信任，并了解文献数据的存储位置和访问控制。

## 从源码构建

独立插件仓库根目录应包含：

```text
README.md
manifest.json
bootstrap.js
bridge.js
assistant.xhtml
assistant.css
assistant.js
build.py
```

在插件仓库根目录运行：

```powershell
python build.py
```

生成文件：

```text
dist/research-assistant-0.2.0.xpi
```

XPI 是 ZIP 格式，正式包只包含：

```text
manifest.json
bootstrap.js
bridge.js
assistant.xhtml
assistant.css
assistant.js
```

## 已知限制

- 当前版本只支持 Zotero `9.x`。
- 插件需要配套的 Research Assistant 后端，不能单独完成解析和检索。
- 当前 `update_url` 是不可用的占位地址，不支持插件内自动更新。
- 云盘自动上传和 WebDAV 凭据配置尚未接入。
- 当前版本没有在真实用户文献库上执行自动化验收。

## 发布新版本

1. 修改 `manifest.json` 中的版本号。
2. 运行插件测试和知识库测试。
3. 重新执行构建脚本。
4. 计算并记录 XPI 的 SHA-256。
5. 在 GitHub 创建与版本号一致的标签，例如 `v0.2.0`。
6. 创建 GitHub Release，并上传生成的 XPI。
7. 在 Release 说明中列出主要改动、兼容版本、验证结果和已知限制。
