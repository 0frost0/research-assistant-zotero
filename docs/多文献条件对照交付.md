# 多文献条件对照（方案 2）

## 已完成

- 复用 `research_assistant/agents/comparison_workflow.py` 的并行单篇分析、综合和一次复核，没有新增第二套 Agent。
- 综合结果增加每篇论文的固定条件摘要：研究对象、方法、数据集/实验设置、指标、结果、适用条件和局限。
- Zotero 工作台在“资料与批注”中为 PDF 增加勾选框；选 2–4 篇后点击“多文献对照”。后端按论文检索文字证据，结论保留证据 ID、页码和 Zotero 跳转。
- 结论关系限制为“共识 / 差异 / 不可直接比较”。不同样本、数据集、时间窗或指标不能直接排名；证据不足时保留缺口。
- 仍有调用预算：论文数 + 综合 + 复核；已有对照任务执行期间拒绝重复提交。

## 为什么这样做

普通多文献问答容易把不同研究条件压成一句“谁更好”。先抽取条件，再判断关系，可以把“结论不同”拆成可核对的样本、方法、设置和指标差异。`StudyProfile` 的证据必须来自同一论文，跨论文比较仍要求至少两篇来源，避免模型把别篇论文的证据挂到当前论文上。

## 使用步骤

1. 在 Zotero 同步分类后打开“科研知识库”。
2. 输入问题，进入“资料与批注”，在第一列勾选 2–4 篇 PDF。
3. 点击“多文献对照”，确认发送命中的文字片段。
4. 先查看每篇论文的条件摘要，再查看共识、差异或不可比结论；点击证据按钮可跳回 Zotero 页码。

## 已验证与限制

- 已验证：`tests/test_comparison.py`（18 项）和知识库/问答专项（42 项）通过；Node Zotero bridge 11 项通过；Python 文件可编译，插件 JavaScript 可通过 `node --check`。
- 仍需真实验证：在用户实际 Zotero 分类中勾选 2–4 篇论文并调用远端模型；当前没有把合成数据结果当作科研质量分数。
- 目前按所选问题检索片段，不是全文系统综述；图片只做定位，未向模型发送像素；模型推测的差异原因会标为待核实。
- 对照接口暂时直接返回结果，服务重启恢复和历史保存仍复用旧 Web 对照入口；Zotero 入口的持久化任务记录可作为下一步增强。
