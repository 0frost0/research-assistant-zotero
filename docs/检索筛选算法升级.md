# 检索与筛选升级（2026-11-09）

> 第一阶段最新验收见 [Qwen Embedding + Reranker](Qwen第一步验收.md)：同一候选池的精排前后对照，不混入后续覆盖与完整性阶段。本文其余内容保留历史多臂实验与接入记录。

## 实际接入

Zotero 默认有据问答（包括“文献与笔记”的原文分支）：

1. 原问题／已有定义扩展 → Qwen 向量召回和 BM25 各最多 40 个文字块。
2. RRF 合并排名（常数 60），不直接相加 BM25 与余弦分数。扩展回当前原文段落并去重，每个查询最多返回 20 个候选。
3. Qwen3-Reranker-0.6B 逐对读取**原问题＋完整候选段落**，每轮最多 40 段、每段 2000 字符、20 秒，不截断条件或否定句。
4. 按精排排序、去除同页包含摘录、保留最多 6 条／12000 字符；逐字引文校验、独立支持性复核和最多一轮纠正不变。

查询的 20 条候选不是底层双路召回总量；精排分数不是证据充分性或科学正确性的概率。普通“检索”和个人记录仍走已有链路，本轮不混入论文原文。

向量索引成功时 BM25 使用 SQLite 中与 `documents.active_version` 一致的有效证据 ID；没有建立向量索引时使用当前分块，仅标记词面降级。知识库范围筛选在召回阶段执行。向量服务失败保留 BM25；精排未配置、超时、身份／分数校验失败时保留原候选顺序并显示警告。错误诊断不保存请求体、密钥或供应商响应。

## 文献依据与实现边界

- [Qwen3 Embedding / Reranking（2025）](https://arxiv.org/abs/2506.05176)：使用[官方 0.6B 模型](https://huggingface.co/Qwen/Qwen3-Reranker-0.6B)，revision `e61197ed45024b0ed8a2d74b80b4d909f1255473`，按 yes/no logits 计算排序分。不是用回答模型充当精排。
- [SetR（ACL 2025）](https://aclanthology.org/2025.acl-long.861/)：借鉴“证据集合需互补”思想，实现查询覆盖＋冗余惩罚的贪心选择；**没有复现 SetR 的训练模型或推理方法**。真实开发用例发现标准锚点丢失，因此保留为 `hybrid_set` 可选实验，未设默认。
- [RINSE（2026-09 预印本）](https://arxiv.org/abs/2609.37469)：强调主题相关不等于证据充分；本轮保留范围复核和不足拒答，**没有实现其三信号充分性判别器**。
- BM25、RRF 属于成熟基础算法，不冒充最新论文创新。

## 消融及已发现失败

四种 `algorithm`：`legacy`、`hybrid`、`hybrid_rerank`、`hybrid_set`。adaptive 默认 `hybrid_rerank`；fixed/selected 默认 legacy，也可显式固定 algorithm。独立评测仍用相同 6 条／12000 字符预算。

- 12 道合成题（9 道有答案）：真实 Qwen＋内存 Qdrant 四组召回均已饱和；精排没有带来召回提升，且 S01 人数题把正确材料从首位降至第二位。不能宣布整体收益。
- 当前真实 6 篇论文的 4 道事实题：按既有源页／逐字摘录锚点检查，精排找回了 MOTOR 的预设参数锚点；互补选择却丢失 RePrompT 数据集题锚点，因此默认不启用集合选择。锚点由助手核对，不是人工封存 test；其他页也可能提供有效答案。
- 两道无答案题可以返回相关候选；仅检索不能证明拒答正确。真实库仍未发现心衰定义，不能用算法生成不存在的证据。

私有报告（不提交论文原文）：`output/retrieval-upgrade-20261109-smoke/ablation/`、`real-library-retrieval.json`。合成报告含合成摘录；真实库报告只存指标、ID和状态。

真实 API＋DeepSeek 验证：MOTOR 参数题 answered（143M），两处返回引文均匹配对应原页，2 次回答／复核调用；“什么是心衰” no_evidence、零结论，2 次回答调用、3 次检索。两题 trace 均为 `hybrid_rerank`，精排均 succeeded；单轮约 0.25–0.31 秒，仅作当前服务诊断。成功两题合计已知 11079 token。首轮 MOTOR 任务与全量测试同时执行时被任务库初始化恢复标记 interrupted；其消费不能按零估算。保留首轮失败报告，停止并行后单题手动复验通过；不是自动重试。真实 API 验收与会导入应用的全量测试不得并行运行。

报告：`live-acceptance.json`（含中断）、`live-motor-recheck.json`、`live-anchor-audit.json`；本次没有人工语义打分，不宣称真实库准确率。
