# 简历项目经历（2026-11-19 更新）

## 推荐投递定位

Agent 应用开发／AI 工程实习。项目名：**Zotero 科研文献与个人记忆助手**。项目起止日期、教育背景、实习出勤和个人贡献待本人确认，不代填。开发使用 AI 辅助，投递前须能独立解释下列实现与实验。

## 可压缩为简历的四条

- 构建 Zotero 插件与 Go 核心产品后端，保留 Python 模型／解析／检索 worker；接通分类同步、混合召回、Reranker 精排及带页码引文的问答，将原文与个人阅读记录分路检索、分区呈现。Go 迁移为 prerelease，未切换生产。
- 实现有界问答编排：原文最多一轮补检索／纠正、4 次模型调用；以来源 ID、逐字引文及模型支持性复核约束输出，并区分证据不足、模型失败和版本冲突。
- 基于 SQLite 实现不可变笔记 revision、乐观并发检查和历史引用回看；已归档记录及未确认 AI 草稿不进入默认检索，异步任务支持取消、中断标记和结果恢复。
- 建立公开 MuSiQue-Full 成对评测，隔离标签与模型输入，冻结模型／数据／配置指纹并校验预测收据；128 对留出问题上，证据链审计相较直接判定的 balanced accuracy 提升 11.33 个百分点。该结果仅属于公开多跳充分性任务，非 Zotero 问答准确率。

## 面试应主动讲的失败

证据证书实验增加“引句逐字核对＋同模型新会话核验”，却损失充分样本召回，因此否决。原因包括引句不忠实与核验器误拒；两次调用不意味着两个独立判断器。SetR-style／QASPER 训练也已保留失败记录，不能写成超过强基线或算法上线。
