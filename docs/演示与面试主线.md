# 科研记忆助手：演示与面试主线

解决的问题：读过论文，不仅要找回原文，还要找回“当时我怎么理解、后来如何修正”。原文是证据，个人理解是有版本的观点，两者不能混用。

## 五分钟演示

1. 在 Zotero 同步一个小分类，问论文的方法或局限，打开引用核对原文。
2. 从证据创建一条“理解”或“疑问”，保留原文摘录与页码。
3. 选择“仅笔记”提问，展示个人记录回答及引用版本 v1。
4. 修改这条理解并保存为 v2。打开旧回答的引用：仍显示 v1，提示已有 v2，不悄悄改变历史依据。
5. 重新提问，核对使用 v2；归档后不再默认召回。编辑中刷新不会丢失文字。

前提：插件需要安装最新 XPI，后端模型已配置，分类已经同步。断网时不能保证远端笔记访问；模型不可用与后端不可用是两种情况。

## 三个值得讲的设计

| 问题 | 设计与取舍 | 可展示依据 |
| --- | --- | --- |
| 模型把个人观点当成论文事实 | 原文与笔记分路检索、分区回答；AI 草稿确认后才参与正式检索 | 同一问题的两类来源与引用 |
| 修改笔记后，旧回答的依据变了 | 追加 revision，乐观并发检查，引用绑定具体版本 | v1 回答与 v2 笔记并存，旧引用只读回看 |
| 检索不足时无限重试、花费不可控 | 有限改写与复核、明确调用上限、失败保留证据 | 任务状态与调用用量记录 |

## 简历草稿

- 开发 Zotero 科研助手，贯通文献同步、证据问答与个人笔记检索，分别展示论文依据和个人理解，支持页码及来源跳转。
- 实现追加式笔记版本与并发冲突检查，历史回答绑定引用 revision；未确认 AI 草稿与归档笔记不进入默认检索。
- 设计有限补检索与纠错问答流程，记录调用状态、延迟和用量；真实科研集效果为【待测】，不使用合成测试代替准确率。
