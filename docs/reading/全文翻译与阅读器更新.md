# 全文翻译与阅读器更新

阅读改进：PDF 画布默认至少 2 倍像素渲染（大页面受内存上限保护），新增“150%阅读”。中文选区加入笔记来源后，点击“补选原文对应段落”，在原文补选并确认，保存后可“返回对应原文”。关联随笔记 revision 保留，属于用户确认，不代表引擎自动对齐或译文准确性认证。

2026-09-10 · **代码与模拟验收完成；新版本真实翻译尚未验证。**

最新调整：按用户要求取消全文单篇及每日总量限制；旧任务默认限额失效，历史用量保留。阅读器显示本次输入/输出 token 和含重试累计，未知用量单列。

| 已实现 | 使用与边界 |
| --- | --- |
| 保留版式全文翻译 | 沿用 pdf2zh-next 2.9.0 / BabelDOC 0.6.2，原件及旧译文不覆盖 |
| 同步翻页 | 对照时左右按钮、输入页码均联动；可关闭，页数不同禁用。只是同物理页码，不声称段落精确对应 |
| 阅读工作台 | 自适应宽度、专注阅读、笔记/译文/提问标签、手机布局、折叠历史任务 |
| 请求账本 | SQLite 增量表保存每次实际 SDK 请求及执行尝试；成功、失败、重试和中断的用量不清零 |
| 循环保护与停止 | 临时错误单次最多尝试 3 次；相同请求失败 3 次或发出 6 次后停止；连续 8 次失败停止新请求。保留手动停止、90 秒请求超时、默认 1800 秒任务超时 |
| 缓存恢复 | 复用引擎持久缓存；已完成段落可复用，排版仍可能重跑。更换影响结果的配置会使缓存失效 |

循环检测按请求指纹，并非语义级循环识别；正常重复内容未命中缓存也可能触发保护。已在途请求仍可能计费。保留每次最多 2048 输出 token，截断时停止，不发布不完整译文。独立付费验证脚本仍保留显式样本预算，不用于正式阅读器。

## 验证结果

以下为此前版本历史验收；本次用量/循环保护的实际回归结果见根目录问题排查笔记 P-066。

- 主环境 174 项：163 通过、11 项因引擎环境隔离跳过；这 11 项在独立引擎环境全部通过。预算专项 11 项与选区几何 3 项通过，见 [机器可读记录](../../benchmarks/reading/verified_results.json)。原有真实翻译结果保留为历史，不作为本轮实测。
- 浏览器 13 项通过：同步/独立/手输翻页、缩放高亮、专注模式、模拟用量、停止、手机无溢出、刷新恢复。选区使用程序化 Range，确认框为隔离模拟；不是本轮原生鼠标拖选或真实模型质量测试。
- 引擎模拟验证包含 Windows spawn 中计量，以及重建翻译器/开启下一次尝试后缓存命中零新增 SDK 请求。
- 两页真实测试首次在配置检查停止，无模型请求；修正配置查找后，自动审批拒绝真实外发。待明确确认 `output/pdf/reading-sample/scientific-en.pdf` → `api.deepseek.com` / `deepseek-v4-flash`，上限 10,000 token 预留/记账、10 次请求、600 秒。
- 本轮未生成新真实译文、未测提速或省钱比例。浏览器使用此前的合成样本译文，不能据此宣称新适配器翻译质量通过。
