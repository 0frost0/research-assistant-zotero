# 自动完整句对齐

更新：2026-09-20。

当前统一以**一个完整句**为最小单位：用户选中句内任意一两个字，浏览器先扩展到该句；选区翻译、高亮、下划线、笔记来源和 AI 草稿都复用同一个整句锚点。译文联动只返回一条完整原文句，不再返回单词或大段落。

| 约束 | 当前行为 |
| --- | --- |
| 模型 | 本地 `cstr/awesome-align-onnx-int8`，不调用付费 API |
| 候选 | 完整中文句对完整英文句；歧义时拒绝，不猜测 |
| 坐标 | 原文和译文分别读取自身 PDF 字符坐标，不按字数或坐标比例换算 |
| 来源 | 紫色为机器建议；蓝色为用户确认；机器结果不会自动升级为正式来源 |
| 版本 | 缓存包含原件、译文和算法版本；重新翻译不迁移旧笔记 |

PDF 排版引擎可能把同一个视觉句拆成多个 text block。解析器只在同页、同栏、视觉连续且前一块没有句末标点时合并；跨栏、跨页和句号后的块不会合并。

验证结果：

- 真实 `Dementia-Agents.pdf`：选中译文“患者”，捕获完整中文句并对齐到唯一完整英文句。
- 浏览器 7 项通过：整句对齐、待确认标识、缩放恢复、关闭清除和持久缓存；付费调用为 0。
- 205 项完整回归通过（17 项按环境跳过）；PDF 几何专项 5 项、服务专项 10 项通过。

已知边界：自动结果仍需核对；扫描件、异常文字层、重复句或语义歧义会明确拒绝。旧词级锚点保留历史，不静默迁移。
