# 翻译失败与等待时间修复

日期：2026-09-09。结论：已修复可确认的错误处理和重试问题；性能设置已经调整，但账户余额不足使真实翻译复验受阻，不能宣称译文质量或速度已达标。

## 已确认的原因

1. 当前 DeepSeek 模型请求返回 HTTP 402。随后只读查询 `/user/balance` 返回 HTTP 200、`is_available=false`，确认账户无可用余额。这是当前无法翻译的直接原因，不能通过更换排版参数修复，也没有代用户充值。
2. 原 worker 将段落请求串行执行（workers=1），并设置 45 秒请求超时。默认 OpenAI SDK 还有重试，上游 OpenAITranslator 又固定最多重试 100 次限流错误。串行和叠加重试会放大等待时间；尚无原始请求计时证明它们各自占前次 901 秒的比例。
3. 原配置使用通用 OpenAISettings，没有设置 DeepSeek V4 的 `thinking`。已核实固定版本提供 DeepSeekSettings 的公开配置转换，支持显式禁用思考模式。但上次是否实际产生 reasoning token 未记录，不能把推测当成确定根因。
4. BabelDOC 的最终段落翻译方法捕获异常后继续，可能保留英文原段落。应用此前补上的长英文残留检查能拒绝明显漏译；本次另外记录脱敏段落错误并阻止带未恢复段落错误的产物发布。

证据来自本机固定版本源码：`pdf2zh_next/translator/translator_impl/openai.py` 的 SDK 初始化和重试装饰器、`config/translate_engine_model.py` 的 DeepSeekSettings.transform，以及 `babeldoc/format/pdf/document_il/midend/il_translator.py` 的异常分支。没有修改 site-packages。

## 实际改动

| 模块 | 行为 |
| --- | --- |
| translation/policy.py | 集中保存运行策略；只对 api.deepseek.com 的 deepseek-v4-* 使用非思考模式，保留用户端点；其他服务不发送 DeepSeek 参数 |
| deployment/translation/worker.py | DeepSeek 先做免费只读余额检查，余额不足立即停止，不启动布局分析和模型健康翻译请求；区分余额、认证、限流、超时等错误 |
| deployment/translation/bounded_client.py | 仅进程内替换固定版本的请求重试包装：SDK 重试设为 0；网络/超时、429、5xx 最多共 3 次调用；400/401/402/403/404/422 不重试，后续新请求也被阻止。已经在途的请求最多受并发数约束 |
| worker 运行配置 | 最大 4 个 worker、QPS 2、单请求超时 90 秒；较长段落给予足够响应时间，整体任务上限仍为 1800 秒。没有通过无限延长任务掩盖失败 |
| translation/service.py | 缓存身份升级到 adapter_version=2，记录思考设置、超时、重试和并发参数；任务只保存白名单数字诊断/耗时/token 汇总及标准错误码，不保存上游原始日志 |
| 用户点击旧任务重试 | 配置升级时使用新身份建立/复用新配置任务，原任务和旧产物不改写；未失败任务不能重试，不自动对旧任务发起付费请求 |

使用上游推荐的 do_translate_async_stream 和原来的 PDF 排版引擎。由于上游没有暴露重试次数配置，适配 shim 依赖固定版本的类/装饰器结构；升级依赖时必须先跑独立环境测试。Windows spawn 会重新导入模块，已测试子进程也启用限制；不能只给父进程打补丁。

上游缓存仍会复用匹配配置的成功段落。新 thinking 参数会进入上游缓存身份，不把旧思考模式结果当作新模式速度测量。没有实现页级检查点/断点续排，也不能保证长文献在 30 分钟内完成。

## 验证与边界

- 真实一条自建句子的模型探测：1.55 秒返回 HTTP 402；没有得到译文。这不是翻译速度测量。
- 真实余额查询：账户不可用；查询本身不消耗模型 token。
- 新 worker 使用前两页授权节选启动：在“检查模型服务账户”阶段返回 `insufficient_balance`，脚本约 6.68 秒结束；没有进入段落翻译。此耗时包含 Python 导入、PDF 节选生成等，不能与 901 秒译文生成直接算提速倍数。
- 固定环境 9 项测试通过：DeepSeek 参数、其他服务隔离、余额预检、网络超时、402 不重试/阻止后续请求、429 的 3 次上限、503 后恢复、日志脱敏及 Windows spawn。HTTP 全部 MockTransport/Mock，不能替代真实模型验收。
- 主环境全套回归与独立环境测试分别报告；主环境有意跳过需要 pdf2zh-next 的专项测试，后者在 `.translation_env` 中实际执行。
- 两页真实翻译的首次 v2 尝试因 402 停止，**尚未生成新译文**；前次摘要漏译和作者/脚注版式缺陷仍未证明消除。
