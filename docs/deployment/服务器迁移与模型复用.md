## 运行

Windows 本地入口：

```powershell
cd D:\workspace\research_assistant
powershell -File scripts/start_server_tunnel.ps1 -LocalPort 8765
```

浏览器打开 http://127.0.0.1:8765/reader 。本地隧道需要保持运行；远端四服务已开启用户 linger，不依赖 SSH 会话存活。所有服务仅监听回环地址。

```sh
cd /home/allon/research_assistant
systemctl --user status research-assistant-{web,qdrant,embedding,mineru}
journalctl --user -u research-assistant-web -n 40
```

环境分离：`.venv` 主应用、`.gpu_env` MinerU/vLLM/Qwen、`.translation_env` 排版翻译、`.alignment_env` 词句对齐。`deployment/setup_linux.py` 只配置运行路径、Qdrant 与用户服务，不自动安装全部依赖。环境版本见同目录 requirements 文件。服务配置重建后执行 `systemctl --user daemon-reload`，仅重启改动的服务。

Docker 无权限，因此使用校验 SHA256 的官方 Qdrant 1.19.1 二进制。向量持久目录 `runtime/qdrant/storage`。英文 OCR 用户态安装在 `runtime/ocr`；没有新增中文 OCR 权重。`.env` 权限 600；文献、密钥均通过 SSH 传输，未复制私钥。
