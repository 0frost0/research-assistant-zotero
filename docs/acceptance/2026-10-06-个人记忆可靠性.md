# 个人记忆与评测隔离验收

本轮解决三处生产可靠性问题，并修复跨平台打包差异；不报告科研回答准确率。

| 问题 | 修复 | 已取得证据 |
| --- | --- | --- |
| 评测读取会把运行中的问答标为中断 | 三个入口使用 SQLite `mode=ro` | 修复前测试复现；修复后任务、数据库字节不变，在线任务仍可完成 |
| 有笔记仍显示 0 | 分别计数快照 `entities` 与 `notes`，排除草稿、归档和空内容 | 原生 Zotero 同步后显示 1，新建专题笔记后显示 2 |
| 快速切库串入旧内容 | 只应用最新请求返回的快照 | 故意颠倒响应顺序，新库内容保持正确 |
| 同源码两平台 XPI 哈希不同 | 固定 ZIP 创建平台字段 | 文件内容相同；修复后三个实测构建哈希一致 |
