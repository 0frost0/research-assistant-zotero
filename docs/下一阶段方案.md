## 研究来源与借鉴边界

- [PaperQA2 论文](https://arxiv.org/abs/2409.13740) / [源码](https://github.com/Future-House/paper-qa)：借鉴搜索、证据收集和回答分离，以及证据排序、状态与成本记录。本轮阅读论文摘要、README 算法段及工具实现片段；源码快照 `57e89f7223b0960d5ee5ea048c69e3c47e088572`。不移植整套文献获取和模型基础设施，不沿用作者的效果结论作为本项目成绩。
- [Self-RAG 论文](https://arxiv.org/abs/2310.11511) / [源码](https://github.com/AkariAsai/self-rag)：借鉴按需检索、相关性及支持性检查。原方法训练带 reflection tokens 的模型；本项目拟采用已有 API 模型和有界工作流，不声称复现 Self-RAG。
- [STORM 论文](https://arxiv.org/abs/2402.14207) / [源码](https://github.com/stanford-oval/storm)：借鉴多角度提问与先收集证据再综合；阅读摘要、README 及 knowledge_curation 实现片段，快照 `fb951af7744dab086e34962e9bc6fe878e145f83`。只用研究对象/方法/实验/局限等角度补足对照，不引入无限角色讨论或整套百科生成系统。

## 如何证明有效

- 先固定 40 道中文问题（20 开发、20 封存测试），记录文献哈希、原文证据、页码；包含模糊找回、精确事实、跨论文比较、笔记与无答案。测试集不用于调参；小样本分项结果同时报告分母和局限。
- 同语料、同生成模型、同上下文预算比较：固定 Top-K → 确定性证据筛选 → 筛选加一次改写/纠正。由增量实验判断 Agent 是否值得保留。
- 自动统计证据 Recall@K、MRR、引用链接有效性、笔记版本正确率、调用次数、实际 token、延迟；人工检查引用是否真正支持结论、错误拒答及跨论文条件是否可比。LLM 复核只是辅助标签。
- 错误引用、重复调用、无答案、网络失败、修改/归档笔记均进入回归集；重试纳入总调用计数并设置超时。具体上限在实现设计中确定，不照搬全文翻译限额。
- 本文不报告新效果分数。部署健康检查、合成测试和真实 Zotero 库验收分别记录。
